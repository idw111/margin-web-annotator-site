Margin — 웹페이지 어노테이션
시행일 2026년 10월 7일 · 확장 프로그램 버전 1.0.0

이 확장 프로그램은 사용자가 웹페이지에서 선택한 텍스트에 메모를 남기고, 같은 페이지를 다시 방문하면 해당 메모를 표시합니다. 메모 데이터는 현재 브라우저의 확장 프로그램 전용 저장 공간에 보관됩니다. 확장 프로그램은 데이터를 개발자나 외부 서버로 전송하지 않습니다.

1. 로컬에서 처리하고 저장하는 정보

사용자가 메모를 저장하면 다음 정보를 현재 브라우저 프로필의 확장 프로그램 전용 localStorage에 기록합니다.

  • 메모를 남긴 페이지의 전체 URL: 경로, 쿼리 문자열, 해시를 포함하며 페이지별 메모를 구분하는 데 사용합니다.
  • 사용자가 선택한 텍스트와 그 앞뒤 각각 최대 64자의 문맥.
  • 선택한 텍스트의 시작·끝 위치, 저장 당시 완전히 같은 문자열의 개수와 선택한 문자열의 순번.
  • 사용자가 작성한 코멘트, 메모 식별자, 메모 생성·수정 시각.

확장 프로그램은 선택한 원문을 찾고 하이라이트를 표시하기 위해 현재 페이지의 주석 대상 본문을 로컬 메모리에서 읽습니다. 페이지 전체 텍스트를 저장하거나 전송하지 않습니다. 입력 필드와 편집 가능한 영역은 주석 대상에서 제외합니다. 별도의 방문 기록 로그를 만들지 않습니다.

2. 이용 목적

저장된 정보는 사용자가 요청한 메모의 작성·조회·수정·삭제, 페이지 주소별 메모 구분, 원문 하이라이트 표시 및 재방문 시 위치 복원에만 사용합니다. 페이지가 다른 주소로 이동하면 이전 표시를 지우고 새 주소에 해당하는 메모를 불러옵니다.

3. 저장 위치와 외부 제공

저장 공간은 확장 프로그램 자체의 오리진에 속하며, 방문한 웹사이트의 localStorage와 분리되어 있습니다. 확장 프로그램은 메모 데이터나 페이지 URL을 개발자·제3자 서버로 전송하지 않고, 판매하거나 광고에 사용하지 않습니다. 분석 도구, 추적 도구, 계정 시스템 및 클라우드 동기화를 사용하지 않습니다. 개발자는 이 확장 프로그램을 통해 사용자의 로컬 메모를 열람할 수 없습니다.

메모 UI는 방문한 페이지 안에 표시됩니다. 로컬 저장은 비밀번호로 잠그거나 별도로 암호화하는 기능이 아닙니다. 같은 브라우저 프로필에 접근할 수 있는 사람이 메모를 볼 수 있습니다.

4. 보관 및 삭제

메모는 사용자가 삭제하거나 확장 프로그램 저장 공간이 제거될 때까지 해당 브라우저 프로필에 남습니다. 개별 메모는 하이라이트 위에 표시되는 카드 또는 확장 프로그램 팝업의 메모 목록에서 삭제할 수 있습니다. 확장 프로그램을 제거하거나 확장 프로그램 저장 공간을 삭제하면 로컬에 저장된 전체 메모가 삭제됩니다.

외부 서버 백업이나 다른 기기와의 동기화 기능은 없습니다. 삭제되거나 브라우저 데이터가 초기화된 메모를 개발자가 복구할 수 없습니다. 페이지 원문이 변경되어 표시를 복원하지 못하더라도 저장된 코멘트는 사용자가 삭제할 때까지 보관됩니다.

5. 사용하는 권한

  • offscreen: 확장 프로그램 내부 문서에서 localStorage에 접근하여 메모를 읽고 저장하고 삭제합니다.
  • activeTab: 사용자가 확장 프로그램 아이콘을 눌렀을 때 현재 페이지 주소를 확인하여 해당 페이지의 메모를 보여주고 원문 위치로 이동합니다.
  • webNavigation: History API나 해시 변경 등 페이지 주소 이동을 감지하여 표시할 메모를 전환합니다.
  • 일반 HTTP/HTTPS 웹페이지의 콘텐츠 스크립트: 텍스트 선택, 메모 UI, 하이라이트 표시 및 재방문 시 자동 복원을 제공합니다.

6. 방침 변경

데이터 처리 방식이 변경되면 이 문서의 내용과 시행일을 수정하여 공개합니다. 이 방침은 위에 표시한 확장 프로그램 버전에 적용됩니다.

소개 사이트와 체험 기능

이 소개 사이트는 GitHub Pages로 제공됩니다. 사이트 제공 과정의 기술적 데이터 처리는 GitHub 개인정보처리방침을 따릅니다. 이 사이트는 자체 분석·광고 도구를 사용하지 않습니다.

소개 페이지의 메모 체험은 확장 프로그램과 별개의 예시입니다. 체험에 입력한 내용은 현재 페이지 메모리에만 보관되며, 새로고침하면 초기화됩니다. 체험 내용은 로컬 저장 공간에 기록하거나 서버로 전송하지 않습니다.
